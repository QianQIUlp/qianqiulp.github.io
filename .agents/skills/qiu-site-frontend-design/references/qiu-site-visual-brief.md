# Qiu Site Visual Brief

## Identity

Qiu's site should feel like a warm study room for slow reading: personal, calm, literate, and practical. It should support long Chinese text, technical notes, reflective essays, project browsing, and contact discovery.

## Design Intent

- Lead with writing and reading, not marketing.
- Keep the interface quiet enough that article content carries the page.
- Use real post covers as content assets where useful.
- Keep navigation consistent and predictable across all routes.
- Make dark mode feel intentional, not inverted as an afterthought.

## Avoid

- Generic AI SaaS gradients.
- Excessive emoji decoration.
- Decorative cards inside cards.
- Large landing-page hero patterns that hide the actual content.
- Adding frontend dependencies to solve static CSS problems.

## Preferred Review Bias

- Prefer small improvements to tokens, spacing, type scale, focus states, and responsive behavior.
- Preserve existing content schema and routes.
- Document low-severity aesthetic preferences instead of turning them into mandatory fixes.
