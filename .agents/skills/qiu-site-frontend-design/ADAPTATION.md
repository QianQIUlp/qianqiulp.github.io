# Adaptation

## Local Name

- Upstream name: `frontend-design`
- Local repo-specific name: `qiu-site-frontend-design`

## Local Scope

Adapted for Qiu's Astro static site:

- Chinese personal blog and portfolio.
- Warm study room visual direction.
- Long-form reading comfort.
- Static Astro routes and Markdown content collections.

## Behavior Changes

- Removed generic new-product/landing-page assumptions.
- Added explicit Astro/static-site boundaries.
- Added local-only file reading policy.
- Added explicit prohibition on runtime remote Markdown/script fetching.
- Added no-new-runtime-dependency and no-framework-change constraints.

## Non-Goals

- This skill does not install UI libraries.
- This skill does not add React, Next.js, Tailwind, shadcn, or package dependencies.
- This skill does not authorize route, content schema, or full redesign changes.
