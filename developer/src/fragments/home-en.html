Q STUDIO / A WORKING PRACTICE

Show the
workings.

The studio is interested in software that stays understandable after the first demo—especially where state lives, why a result appeared, and what the tool cannot know.

  1. 01 /

    Keep it close.

    Useful work and private state should live on the user's device by default.

  2. 02 /

    Leave a trace.

    Expose observations, history, and capability states so a decision can be checked.

  3. 03 /

    Draw the edge.

    State the limit in the same breath as the capability. Unknown is a useful answer.
