# 墨光书房 · Ink & Light Study

本站现行视觉实现契约。改首页前先读 [`homepage-art-direction.md`](./homepage-art-direction.md)，
再读 [`person-first-intent.md`](./person-first-intent.md)，最后用本文件约束实现的一致性。
这里的规则服务于创作方向，不取代构图、明暗与留白的感性判断。

## 一句话 Thesis

这是一间**入夜亮灯、晨起铺宣的书房**。初见时，光只留下千秋、吉他与一点生活气息；
书桌、工作台和更多信息先沉在墨影里，等读者自己靠近才显出来。进入内页后，空间收成适合慢读的纸面。
昼为宣纸，夜为墨。

## 设计来源：界画四原则

视觉语言借自中国界画的观看方式。四个融合原则是**当前视觉层**的一致性依据，
上位创作判断仍以首页艺术方向与人本意图为准：

1. **统一纸底** — `--paper` 与 `--paper-raised` 回到 `--bg`；`--surface-*` 只是一层透明墨洗，
   不生成第二块"底板色"卡片。信息分层靠留白、墨线、浓淡，不靠背景色堆叠。
2. **统一光源** — 全站只有一个光源：左上方。阴影统一向右下落，灯光（glow）统一自左上来。
   新增任何投影/光晕前，先问"它的光从哪来"。
3. **边缘墨化** — 内容边缘不做硬切割：图片用晕影（vignette）或渐隐融入纸底，
   不用直角描边框住一幅画。
4. **墨分五色** — 单色内分层次：焦浓重淡清五级墨色承担全部层级
   （标题/正文/次要/辅助/装饰），不靠色相变化区分重要度。
   全站唯一的彩色例外是**朱砂**。

## 主题系统：昼宣 · 夜墨

- `html[data-theme="dark"]` 为夜墨（默认），浅色为昼宣；选择存 `localStorage.theme`。
- **昼宣**：内页仍是适合长读的宣纸；首页则与夜墨共用黑色舞台、墨影、文字和控件材质，
  主题差异只由严格配准的 day/night 摄影资产承担。浅色主题直接使用低噪点白天摄影图，
  不再叠加纸光池、浅色悬浮底板或另一套前景滤镜。
- **夜墨**：灯从窗外与台灯来，大面积焦墨退远，内容浮在灯光里。
- 两主题必须是**同一构图、同一物件、同一物理空间**：配对资产只允许时间、灯态、曝光与
  由此产生的阴影变化；任何元素不允许消失、移位或改变接触关系。

### 晕染转场

主题切换不是生硬替换：旧色以圆形 clip-path 从切换按钮位置**收拢退场**，
同时带一层雾化（blur 渐隐），像一滴墨在宣纸上晕开又淡去。
实现在 `BaseLayout.astro` 内联脚本 + `global.css` `.theme-wipe`。
转场期间必须：`prefers-reduced-motion` 即时切换、连点不残留遮罩（activeAnims 守卫 + 兜底清理）。

## 色彩契约

层级靠墨色五色，不靠彩色：

| Token | 角色 | 用途 |
| --- | --- | --- |
| `--ink-jiao` 焦 | 最重 | 大标题、印章文字底 |
| `--ink-nong` 浓 | 正文/标题 | 正文、卡片标题 |
| `--ink-zhong` 重 | 次要 | 摘要、元信息 |
| `--ink-dan` 淡 | 辅助 | 日期、注释、边框重色 |
| `--ink-qing` 清 | 最轻 | 分割线、装饰、禁用态 |
| `--cinnabar` 朱砂 | 唯一彩色 | 印章、朱批、卷/题标签、题跋侧签 |
| `--glow-lamp` 灯光 | 光 | 悬停光晕、纸光池、夜墨高光 |
| `--paper-*` | 纸底 | 全站唯一底板 |

铁律：

- 新增颜色前先映射到上面某一格；映射不进去的颜色不许出现。
- 朱砂只用于"落款/批注"语义的场合（印章、朱批、卷题、侧签），**不用于**普通按钮、链接悬停、报错。
- 链接与可交互文本的默认态不用朱砂；朱砂是"印上去的"，不是"画上去的"。

## 字体契约

- 标题：**Noto Serif SC / Songti SC**；正文与 UI：系统无衬线。长中文阅读保持稳定行高，
  字体职责不因页面变化而互换。
- 书体 **QiuBrush**（Long Cang 子集，`public/fonts/qiu-brush.woff2`，11.4KB）只许出现在两类文字：
  1. 空文章封面的落款「千秋」
  2. 目录侧栏「目录」题字
- 首页「我是千秋。」使用与项目页「作品与探索」相同的正常宋体系标题字（`var(--font-serif)`、700），
  不再使用 QiuBrush 书体。
- 书体是**签名**，不是装饰字体：组件标题、按钮、导航、正文一律不用。
- 增补字：改 `scripts/signature-font-chars.txt` 后跑 `scripts/subset-signature-font.py`
  （需 fonttools+brotli 环境，参考脚本头部注释）。

## 印章契约

站点界面不再显示「千秋」朱砂印章。页眉只保留正常文字品牌；文章授权协议使用文字文末记，
文章卡片的空封面落款仍可用笔字「千秋」，但不得伪装成印章。

## 显影（签名动效）

滚动进入视口的内容以 `data-reveal` **显影**：轻微上移 + 由虚到实（含极轻 blur 收敛），
如同墨迹在纸上显出来。这是内容列表唯一的入场动效签名；房间视线移动、主动探索显隐与主题转场
属于交互反馈，不另给内容新增弹入或翻牌；
不要再引入第二种入场方式（弹入、翻牌、视差滚屏都不许）。

## 氛围层

`BaseLayout` 的 `.atmosphere`：夜墨为墨絮、昼宣为花瓣（首页另有 `room-petals`）。
数量少（个位数）、速度慢、透明度低、`pointer-events: none`、`prefers-reduced-motion` 下静止。
氛围层是"空气"，任何情况下不得遮挡可读性。

## 首页房间

首页创作方向以 `homepage-art-direction.md` 为准：**东西很多，初见很少**。
初始全景只把题字、吉他和生活入口留在光里；完整站点导航、书桌与工作台先退入墨影。
桌面端停留或键盘聚焦会让目标所属的整块舞台黑幕缓慢淡去，文章、作品与生活互不串光；
走近并回到全景后，当前会话累计保留所有已访问区域。三块都访问后黑幕完全退场，
从具体文章返回首页时亦保留这份累计发现。
这是一种空间发现，不显示步骤、完成度或 onboarding 面板。

叙事结构：人物与吉他初见 → 暗处被发现 → 近景（writing/projects/life）→ 「回到房间」。
昼夜 overview 均预载，保证主题切换不露底；两组近景图 `loading="lazy"` + 低 `fetchpriority`。

- 构图锁：场景图水平翻转必须与文案栏位置匹配（见 `home-room.css` 顶部注释）；
  改文案栏宽度/位置时同步检查热点坐标（热点以百分比锚在场景上）。
- 近景面板即"屏幕/物件本身"；电脑与工作台各使用严格配准的昼夜写实图。代码界面必须落在
  真实显示器或真实桌面支撑平面上，不能用独立产品视角、悬浮投影或穿透桌面的接触关系。
- 昼夜电脑内容始终显示在深色真实屏幕内，不随浅色主题变成宣纸卡片。工程近景严格服从作者标注图：
  MealCircuit 位于左上桌面（约 left 11% / top 19.2%），Crewlight 位于左下机架（约 left 12.3% / top 61.5%），
  Docker-Hadoop-Cluster 位于右下桌沿（约 left 47.8% / top 49.8%）。这些百分比按 16:9 场景画布校准，
  已包含宽屏画布高于视口产生的垂直偏移；卡片必须正放，不得擅自重组为三角群组。
- 液态玻璃只用于三张项目卡：背景必须保持清晰可辨，禁止用高半径 blur 做成毛玻璃；透明环境取色、
  高饱和/对比的背景采样、清晰亮边、内侧折射暗边、局部高光与尺度对应的投影共同表现液体厚度。
  昼夜按钮、返回按钮和分区标题不得套用该材质，避免全屏玻璃化。
- 窄屏工程近景以 `object-position` 把 Supro 箱头作为主要背景；卡片改为轻微错宽的纵向节奏，仍须让箱头与木桌可辨。
- 房间材质遵循物理真实：墙面为雪白哑光漆，木、金属、织物、皮革、橡胶各有独立真实纹理；
  禁止把颗粒、纸纹、浮雕虫纹或同一种生成纹理铺到所有材质上。
- 移动端：场景退为背景，三个热点从首次加载起就稳定呈现为底部 dock，文案在上；
  不要求先进入「吉他 / 生活」再返回才能看见文章与作品入口。

## 内页语言

- **乌丝栏**：blog 列表、文章页题头与 projects 卷宗用双线墨栏（`post-ledger`、`post-header`、featured-work），
  灵感来自古籍栏线。双墨线 = "这是一卷"。
- **卷/题**：朱砂小字标签（`page-kicker` 体系）标在栏首，如「卷·随笔与笔记」。
- **题跋**：文章页导读以朱砂左边线 + 侧签出现，只放真正的"批注"性内容，不再套第二层卡片底板。
- **朱批**：`case-study__side`、`workbench-note` 等侧注用朱砂系，正文墨色。
- **文末记**：文章结尾以墨线与文字写授权协议，不使用印章。
- **目录**：所有文章自动生成目录，不再依赖单篇 frontmatter 开关；即使正文没有二至四级标题，
  也至少提供「文章开头」。目录以原生 `details` 固定在视口左中，可由同一按钮展开与收起，
  不挤压正文；书体只用于「目录」题字，并配朱砂下划线。
- **正文排印**：`text-spacing-trim: trim-all`、`hanging-punctuation`、`text-wrap: balance`
  （标题），中文标点挤压已开启——新增正文容器继承 `.post-content` 规则，不要覆盖。

## 灯光系统

夜墨的可交互元素悬停时浮起一层**灯光**（`--glow-lamp` 径向光晕），
像台灯照亮了那一件东西。昼宣悬停是纸光池变亮。任何悬停反馈要么"灯亮"，要么"墨淡"，二选一，不叠加第三种。

## Do / Don't（防漂移）

**Do**

- 新页面先套 `BaseLayout` + `page-kicker` + `post-ledger`/双线墨栏骨架。
- 分层用留白与墨色浓淡；投影用 `shadow-sm` 级，方向右下。
- 首页先退远看明暗和视线顺序，再检查组件规则；不要用更多文案补救构图没有说清的东西。
- 改动后跑 `npm run build`，并按 `docs/qa/visual-checklist.md` 双主题截图验证。

**Don't**

- 不许引入第二种底板色、第二种强调色、第二种入场动效、第二种"印章"。
- 不许把朱砂当品牌主色铺满按钮/链接。
- 不许用书体排组件标题或正文。
- 不许在昼宣主题隐藏元素或改变构图。
- 不许加运行时依赖解决 CSS 问题（站点硬约束）。
- 不许给卡片套卡片；嵌套信息用墨线与缩进。
- 不许把首页做成内容总览、人物属性清单或分步教程。

## 变更守卫

任何视觉改动提交前：

1. `npm run build` 通过。
2. `docs/qa/visual-checklist.md` 中受影响条目双主题（昼/夜）过一遍。
3. 首页改动反查 `homepage-art-direction.md`；触碰本契约描述的系统（色彩/字体/印章/显影/转场/房间），同步更新本文件与
   `.agents/skills/qiu-site-frontend-design/`。
