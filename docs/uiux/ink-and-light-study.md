# 墨光书房 · Ink & Light Study

本站现行视觉契约。任何页面、组件、样式、文案的改动，先读这份文档，再动手。
旧契约 `person-first-editorial-system.md` 已废止（仅留档）。

## 一句话 Thesis

这是一间**入夜亮灯、晨起铺宣的书房**：读者推门（首页房间）看见人与吉他，
点击物件让视线走过去（场景近景），展开卷轴读文章（乌丝栏），盖一枚朱砂印作落款（印章）。
昼为宣纸，夜为墨。

## 设计来源：界画四原则

视觉语言借自中国界画的观看方式，四个融合原则是全站所有视觉判断的最高依据：

1. **统一纸底** — 所有页面共享同一张纸（`--paper-*`），不允许出现第二块"底板色"卡片。
   信息分层靠留白、墨线、浓淡，不靠背景色堆叠。
2. **统一光源** — 全站只有一个光源：左上方。阴影统一向右下落，灯光（glow）统一自左上来。
   新增任何投影/光晕前，先问"它的光从哪来"。
3. **边缘墨化** — 内容边缘不做硬切割：图片用晕影（vignette）或渐隐融入纸底，
   不用直角描边框住一幅画。
4. **墨分五色** — 单色内分层次：焦浓重淡清五级墨色承担全部层级
   （标题/正文/次要/辅助/装饰），不靠色相变化区分重要度。
   全站唯一的彩色例外是**朱砂**。

## 主题系统：昼宣 · 夜墨

- `html[data-theme="dark"]` 为夜墨（默认），浅色为昼宣；选择存 `localStorage.theme`。
- **昼宣**：同一空间被晨光洗过——高亮度、低饱和、纸色微暖。实现方式是对场景做
  `brightness/saturate/contrast/sepia` 滤镜 + 宣纸罩（`room-canvas::before`），
  而不是换一套"白底网站"的样式。昼态的文字元素坐在纸光池（paper-glow veil）里。
- **夜墨**：灯从窗外与台灯来，大面积焦墨退远，内容浮在灯光里。
- 两主题必须是**同一构图**：任何元素不允许在某一主题下消失或移位（允许明暗、浓淡变化）。

### 晕染转场

主题切换不是生硬替换：旧色以圆形 clip-path 从切换按钮位置**收拢退场**，
同时带一层雾化（blur 渐隐），像一滴墨在宣纸上晕开又淡去。
实现在 `BaseLayout.astro` 内联脚本 + `global.css` `.theme-wipe`。
转场期间必须：`prefers-reduced-motion` 即时切换、连点不残留遮罩（activeAnims 守卫 + 兜底清理）。

## 色彩契约

层级靠墨色五色，不靠彩色：

| Token | 角色 | 用途 |
| --- | --- | --- |
| `--ink-jiao` 焦 | 最重 | 大标题、印章文字底 |
| `--ink-nong` 浓 | 正文/标题 | 正文、卡片标题 |
| `--ink-zhong` 重 | 次要 | 摘要、元信息 |
| `--ink-dan` 淡 | 辅助 | 日期、注释、边框重色 |
| `--ink-qing` 清 | 最轻 | 分割线、装饰、禁用态 |
| `--cinnabar` 朱砂 | 唯一彩色 | 印章、朱批、卷/题标签、题跋侧签、强调链接 |
| `--glow-lamp` 灯光 | 光 | 悬停光晕、纸光池、夜墨高光 |
| `--paper-*` | 纸底 | 全站唯一底板 |

铁律：

- 新增颜色前先映射到上面某一格；映射不进去的颜色不许出现。
- 朱砂只用于"落款/批注"语义的场合（印章、朱批、卷题、侧签），**不用于**普通按钮、链接悬停、报错。
- 链接与可交互文本的默认态不用朱砂；朱砂是"印上去的"，不是"画上去的"。

## 字体契约

- 正文/UI/标题：**Noto Serif SC**（宋体系），全站唯一正文字族。
- 书体 **QiuBrush**（Long Cang 子集，`public/fonts/qiu-brush.woff2`，11.4KB）只许出现在四类文字：
  1. 首页题字「我是千秋。」与副题
  2. 空文章封面的落款「千秋」
  3. 文章页/页脚的印章旁落款
  4. 目录侧栏「目录」题字
- 书体是**签名**，不是装饰字体：组件标题、按钮、导航、正文一律不用。
- 增补字：改 `scripts/signature-font-chars.txt` 后跑 `scripts/subset-signature-font.py`
  （需 fonttools+brotli 环境，参考脚本头部注释）。

## 印章契约

`src/components/Seal.astro`：白文「千秋」方印，朱砂底。
使用位置：站点页眉（品牌位）、页脚、文章页授权协议落款。**每屏至多一枚**；
文章卡片的空封面落款用笔字「千秋」而非印章（印只盖一次的地方才贵重）。

## 显影（签名动效）

滚动进入视口的内容以 `data-reveal` **显影**：轻微上移 + 由虚到实（含极轻 blur 收敛），
如同墨迹在纸上显出来。这是全站唯一的入场动效签名；
不要再引入第二种入场方式（弹入、翻牌、视差滚屏都不许）。

## 氛围层

`BaseLayout` 的 `.atmosphere`：夜墨为墨絮、昼宣为花瓣（首页另有 `room-petals`）。
数量少（个位数）、速度慢、透明度低、`pointer-events: none`、`prefers-reduced-motion` 下静止。
氛围层是"空气"，任何情况下不得遮挡可读性。

## 首页房间

叙事结构：全景 overview（人与吉他开场）→ 点击热点（呼吸微光）→ 近景（writing/projects/curtain/life）
→ 「回到房间」。近景图 `loading="lazy"` + 低 `fetchpriority`，overview 预载。

- 构图锁：场景图水平翻转必须与文案栏位置匹配（见 `home-room.css` 顶部注释）；
  改文案栏宽度/位置时同步检查热点坐标（热点以百分比锚在场景上）。
- 近景面板即"屏幕/物件本身"，昼夜两态共用同一张写实近景图，不做昼版滤镜——
  滤镜只作用于"房间空间"（overview/curtain/guitar）。
- 移动端：场景退为背景，热点折叠为底部 dock，文案在上。

## 内页语言

- **乌丝栏**：blog 列表与文章正文用 4px 双线墨栏（`post-ledger`、featured-work、projects 卷宗），
  灵感来自古籍栏线。双墨线 = "这是一卷"。
- **卷/题**：朱砂小字标签（`page-kicker` 体系）标在栏首，如「卷·随笔与笔记」。
- **题跋**：文章页侧栏 note 卡（朱砂左边线 + 侧签），只放真正的"批注"性内容。
- **朱批**：`case-study__side`、`workbench-note` 等侧注用朱砂系，正文墨色。
- **落款**：文章结尾印章 + 授权协议。
- **目录**：书体「目录」题字 + 朱砂下划线。
- **正文排印**：`text-spacing-trim: trim-all`、`hanging-punctuation`、`text-wrap: balance`
  （标题），中文标点挤压已开启——新增正文容器继承 `.post-content` 规则，不要覆盖。

## 灯光系统

夜墨的可交互元素悬停时浮起一层**灯光**（`--glow-lamp` 径向光晕），
像台灯照亮了那一件东西。昼宣悬停是纸光池变亮。任何悬停反馈要么"灯亮"，要么"墨淡"，二选一，不叠加第三种。

## Do / Don't（防漂移）

**Do**

- 新页面先套 `BaseLayout` + `page-kicker` + `post-ledger`/双线墨栏骨架。
- 分层用留白与墨色浓淡；投影用 `shadow-sm` 级，方向右下。
- 改动后跑 `npm run build`，并按 `docs/qa/visual-checklist.md` 双主题截图验证。

**Don't**

- 不许引入第二种底板色、第二种强调色、第二种入场动效、第二种"印章"。
- 不许把朱砂当品牌主色铺满按钮/链接。
- 不许用书体排组件标题或正文。
- 不许在昼宣主题隐藏元素或改变构图。
- 不许加运行时依赖解决 CSS 问题（站点硬约束）。
- 不许给卡片套卡片；嵌套信息用墨线与缩进。

## 变更守卫

任何视觉改动提交前：

1. `npm run build` 通过。
2. `docs/qa/visual-checklist.md` 中受影响条目双主题（昼/夜）过一遍。
3. 改动若触碰本契约描述的系统（色彩/字体/印章/显影/转场/房间），同步更新本文件与
   `.agents/skills/qiu-site-frontend-design/`。
