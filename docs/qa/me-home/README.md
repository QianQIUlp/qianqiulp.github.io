- `npm run build` 通过，生成 20 个页面。Vite 提示 Three.js 所在模块超过 500 kB；没有新增包，也没有修改音频算法或吉他几何。
- 中英文首页的资源和站内链接均指向实际构建文件；无 `_room` / `rewrite.html` 原型路径，canonical、alternate、robots 和 sitemap 使用 me.qiu.works。
